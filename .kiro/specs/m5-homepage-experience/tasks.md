## Overview

This file defines the 10-goals skeleton for M5. Individual task detail (~10 tasks per goal) is generated by Stage 3 (Google AI Studio) into separate `goal1.md`–`goal10.md` files in this directory.

Each task in the generated goal files must be fully self-contained for stateless orchestrator execution (Nomic retrieval, gemma-3-1b router, gemma-4-e2b executor, router audit). No inter-task conversation history is assumed.

M5 delivers the static homepage `/` (`SCR-01`): pure helpers in `src/lib/home/`, the display-date formatter, five server section components and `HomeContent` in `src/components/home/`, and `src/app/page.tsx` with `generateMetadata`. M5 has zero client components and composes M3 primitives and the M4 shell without modifying them.

## Notes

### Cross-Goal Notes

- **No client components:** Every M5 module is a server component or a plain function. Responsive layout is Tailwind utilities; dates are formatted at build time.
- **Pure helpers, separate from rendering:** All selection, derivation, visibility, and metadata logic lives in `src/lib/home/` and imports no React, so it is testable without rendering (Req 16.6).
- **One visibility rule:** `getVisibleSections` is the single source for which sections render; `HomeContent` and tests both use it. Featured keeps its heading with an `EmptyState`; Skills, Certifications, and Recent are omitted entirely when empty.
- **Single skills group:** M2 `Project` has no category field, so `deriveSkillGroups` returns one `Technologies` group. Categories must not be invented.
- **Formatter reuse:** G1.T5 searches M2–M4 for an existing date formatter first (Req 12.5); G1.T6 is skipped if one is found.
- **Scope guard:** M5 edits only `src/app/page.tsx`, `src/components/home/`, `src/lib/home/`, `src/lib/format-date.ts`, and `tests/`. Missing primitives, tokens, or dependencies are recorded in `task-notes.md` and escalated (`AGENTS.md` 6.2), never patched.
- **Deferred verification:** Link targets `/projects/{slug}`, `/certifications`, `/blog`, and `/blog/{slug}` resolve only after M6–M8; M5 verifies hrefs, not destinations.

### Testing Patterns

- Property tests use `fast-check` (no hand-rolled generators), at least 100 iterations each, and a tag comment: `Feature: m5-homepage-experience, Property N: <text>`.
- Render-based property tests call `cleanup()` between iterations and use bounded array sizes.
- Loaders are mocked with `vi.mock` using fixtures from `tests/fixtures/home-data.ts`.
- Date tests set `process.env.TZ` per case; selection tests use deeply frozen inputs to detect mutation.
- jsdom does not evaluate Tailwind; CSS layout, overflow, contrast, and focus visibility are covered by the manual verification list.
