## Goal Objective

Harden `tsconfig.json` to enforce strict type checking across the entire codebase. This eliminates unsafe coding practices, explicitly forbids `any` types and unjustified assertions, enables indexed access safety, validates module resolution, maps path aliases (`@/*` $\rightarrow$ `./src/*`), and establishes a deterministic `npm run typecheck` script to gate CI and build pipelines.

- ✓ `tsconfig.json` contains `"strict": true` along with all explicit strict-family compiler flags

- ✓ Path alias mapping `@/*` pointing to `./src/*` is active and verifiable
- ✓ `package.json` contains a working `"typecheck": "tsc --noEmit"` script
- ✓ Executing `npm run typecheck` in PowerShell exits cleanly with code 0

### M1.G2.T7: Configure Library Checking and Next.js Plugins

**Objective:** Configure `skipLibCheck` and register the Next.js TypeScript compiler plugin.

**Acceptance Criteria:**
- ✓ `skipLibCheck` is explicitly set to `false` per Req 2.9 (or set to `false` with `skipDefaultLibCheck: false`)
- ✓ `plugins` array contains `[{"name": "next"}]`

**Prerequisites:**
- M1.G2.T6 completed
- Target file: `c:\dev\andres-webapp-professional\personal-website-portfolio\personal-website-portfolio-v2\tsconfig.json`

**Implementation Details:**
Execute the following PowerShell script:
```powershell
cd "c:\dev\andres-webapp-professional\personal-website-portfolio\personal-website-portfolio-v2"
$config = Get-Content "tsconfig.json" -Raw | ConvertFrom-Json

$config.compilerOptions.skipLibCheck = $false
$config.compilerOptions.skipDefaultLibCheck = $false

$pluginExists = $false
if ($config.compilerOptions.plugins) {
    foreach ($p in $config.compilerOptions.plugins) {
        if ($p.name -eq "next") { $pluginExists = $true }
    }
}
if (-not $pluginExists) {
    $config.compilerOptions | Add-Member -MemberType NoteProperty -Name "plugins" -Value @(@{ name = "next" }) -Force
}

$config | ConvertTo-Json -Depth 10 | Set-Content "tsconfig.json" -Encoding UTF8
```

**Validation:**
