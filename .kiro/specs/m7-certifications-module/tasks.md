## Overview

This file defines the 10-goals skeleton for M7. Individual task detail (~10 tasks per goal) is generated by Stage 3 (Google AI Studio) into separate `goal1.md`–`goal10.md` files in this directory.

Each task in the generated goal files must be fully self-contained for stateless orchestrator execution (Nomic retrieval, gemma-3-1b router, gemma-4-e2b executor, router audit). No inter-task conversation history is assumed.

M7 delivers the Certifications module: the single static route `/certifications` (`SCR-04`), six presentational components in `src/components/certifications/` (`CertificationsIndex`, `CertificationCategorySection`, `CertificationCard`, `VerificationLink`, `BadgeImage`, `ExpiredIndicator`), and pure helpers in `src/lib/certifications/` for category order and labels, grouping, expiry classification, verification href and badge source validation, heading shifting, supporting-content loading, and metadata. M7 composes M2 loaders, M3 primitives, the M4 shell, and the M5 `formatDisplayDate` and `compareStrings` without modifying them. M7 ships zero client JavaScript: no `'use client'` module, no `Suspense` island, no detail route. The only clock read is one `buildDate` expression in `page.tsx`, passed down as an argument.

## Notes

### Cross-Goal Notes

- **Zero client JavaScript:** No M7 file has `'use client'`, state, effects, or browser APIs. There is no `Suspense` island because certifications have no interactive state in P0.
- **One clock read:** `buildDate` is computed once in `page.tsx` and passed through `CertificationsIndex` to every card. Helpers take it as an argument. Status therefore reflects the build day, which is accepted for static export; dates stay visible on each card.
- **Defense in depth:** M2 validates `verificationUrl` and badge fields. Components re-check through `getVerificationHref` and `getBadgeSource` and omit the element rather than render something unsafe or inaccessible.
- **Plain `img` for badges:** `next/image` is avoided because no `next.config` images setting is guaranteed; a justified ESLint disable documents this. Only the first card loads eagerly.
- **Unique link names:** Link names use the certification title; a fixture test flags duplicate titles for the Content Owner.
- **Heading outline:** `h1`, `h2` per category, `h3` per card, `h4` or lower in supporting content via local `shiftHeadings` (no import from M6).
- **Uncategorised is defensive:** The fallback group is unreachable for M2-validated content and is tested through a test-only cast.
- **Reuse, do not recreate:** `formatDisplayDate` and `compareStrings` come from M5. If either is missing, G1.T7 stops and escalates.
- **Scope guard:** M7 edits only `src/app/certifications/`, `src/components/certifications/`, `src/lib/certifications/`, `tests/`, and optionally `content/certifications/` and `public/images/certifications/` (Content Owner supplied only). Missing primitives, tokens, or dependencies are recorded in `task-notes.md` and escalated (`AGENTS.md` 6.2), never patched.
- **Deferred verification:** Layout, overflow, contrast, and real keyboard traversal are not evaluated by jsdom and are covered by the manual list; performance work is M9.
