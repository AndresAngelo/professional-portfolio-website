# Stage 0: Hermes Local AI Setup & Context Gatherer

## Purpose
Stage 0 is the foundational context and conversation gatherer. Powered by Hermes Agent connected to a local Obsidian vault (second brain), it maintains persistent user context, technical preferences, and session history. It acts as the primary orchestrator to ingest raw user intent and formulate optimal meta-prompts and directives for all downstream pipeline stages.

## Core Responsibilities
- Gather, index, and retrieve user conversation history and technical constraints from the local Obsidian vault.
- Translate raw user requirements into targeted, high-context meta-prompts for Stage 1 through Stage 5.
- Ensure strict adherence to the zero-hallucination, free-tier local engineering mandate.
